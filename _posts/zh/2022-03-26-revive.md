又一次尝试用 github 来托管个人网站。看起来 Jekyll 是默认支持的。

Jekyll 对代码片段的支持也很不错：

{% highlight ruby %}
def print_hi(name)
  puts "Hi, #{name}"
end
print_hi('Tom')
#=> prints 'Hi, Tom' to STDOUT.
{% endhighlight %}

更多用法可以看 [Jekyll 文档][jekyll-docs]。Bug 和功能需求都提到
[Jekyll 的 GitHub 仓库][jekyll-gh]；有问题也可以到 [Jekyll Talk][jekyll-talk] 上提问。
